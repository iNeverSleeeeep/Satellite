# 建模与命名约定

本文档汇总当前工程中与坐标系、姿态表示、状态命名和变量缩写相关的基本约定。

## 坐标系缩写

- `i`：惯性系
- `b`：星体系 / 机体系
- `f`：地固系
- `e`：地球固定参考系或地固中间表达，具体以文件注释为准

## 方向余弦矩阵

本项目采用“目标坐标系在前，原坐标系在后”的命名方式：

- `DCM_bi`：将惯性系向量转换到机体系
- `DCM_ib`：将机体系向量转换到惯性系
- `DCM_if`：将地固系向量转换到惯性系
- `DCM_bf`：将地固系向量转换到机体系

对应关系示例：

```matlab
v_b = DCM_bi * v_i;
v_i = DCM_ib * v_b;
v_b = DCM_bf * v_f;
```

## 四元数

四元数建议和方向余弦矩阵保持同一方向定义：

- `q_bi`：表示从惯性系到机体系的姿态四元数
- `q_bi_0` 或 `q_b0`：初始姿态四元数

如果 `q2dcm(q_bi)` 输出的是惯性系到机体系的矩阵，则可直接得到 `DCM_bi`。

## 角速度与角加速度

角速度默认表示“机体系相对惯性系的角速度，且分量在机体系表达”：

- `omega_b`：机体系角速度
- `omega_dot_b`：机体系角加速度
- `omega_b0`：初始机体系角速度

如果后续模型中会同时出现多种相对角速度，可使用更完整写法，例如 `omega_bi_b`，但在当前阶段不建议把常用变量命名得过长。

## 平动状态

平动主状态如果在惯性系积分，统一命名为：

- `X_i`：惯性系位置
- `V_i`：惯性系速度
- `A_i`：惯性系加速度

如果需要同时输出地固系状态，可写为：

- `X_f`
- `V_f`
- `A_f`

## 参考方向与测量方向

在姿态确定和姿态估计链路中，通常区分“惯性系参考方向”和“机体系测量方向”：

- `sun_i`：惯性系下太阳参考方向
- `mag_i`：惯性系下地磁参考方向
- `sun_b`：机体系下太阳测量方向
- `mag_b`：机体系下磁场测量方向

它们的典型用途是：

- `sun_i` / `mag_i` 由环境参考模型给出
- `sun_b` / `mag_b` 由传感器测量或重建得到
- TRIAD / EKF 利用这两组对应方向完成姿态确定与姿态修正

## 传感器配置约定

传感器配置统一集中在 `sensorConfig` / `sensorSuite` 结构体中，常见字段包括：

- `enabled`：开关
- `mode`：模式切换
- `noiseStd` / `noiseStdT`：噪声标准差
- `returnUnitVector`：是否输出单位方向向量
- `calibration`：标定参数
- `css`：粗太阳敏感器阵列参数

## 环境模型模式约定

环境参考模型当前支持按模式切换：

- `simple`：快速原型模式
- `engineering`：工程近似模式
- `high_fidelity`：高保真模式

这类模式统一由 `environment_config` 中的字段控制，例如：

- `env.sunModel`
- `env.magneticModel`

## 关于高保真模式

高保真模式并不意味着工程必须联网或动态依赖外部服务。更准确地说：

- 地面仿真阶段通常会调用成熟工具箱、参考实现或权威模型库
- 飞行软件阶段通常会把这些算法裁剪、移植并固化进自己的工程代码
- 因此“依赖权威模型”和“在轨动态依赖第三方库”并不是一回事
